# حسابدار

فضای کار فایل و داده. کاربر فایل جدولی را وارد می‌کند و سیستم همان فایل را نگه می‌دارد تا در بخش‌های بعد روی آن کار شود.

نام نمایشی محصول **حسابدار** است. نام مخزن `heasabdar` است.

## وضعیت

بخش صفر تا یازده انجام شده‌اند. جزئیات و عددهای اندازه‌گیری در [docs/status.md](docs/status.md).

الان می‌توانید فضای کار بسازید، فایل را وارد کنید، ساختارش را ببینید، یک نسخه پاک‌شده بسازید و دو فایل را مغایرت بگیرید. گفتگو رتبه، روند، نمودار، داشبورد و گزارش مدیریتی را هم اجرا می‌کند. فرمول زنده با برچسب ارزیابی‌نشده نوشته می‌شود. از گفتگو می‌شود فایل مدیریت فروش ساخت، دو برگه را ادغام کرد و خروجی csv امن گرفت. تاریخچه نسخه روی صفحه است و بازگشت، نشانگر را به همان نسخه برمی‌گرداند بدون این‌که نسخه‌های میانی حذف شوند. عملیات ناتمام بعد از قطع، موفق نشان داده نمی‌شود.

## اجرای محلی

دو فرآیند لازم است. هر دو فقط روی همین رایانه گوش می‌دهند.

ترمینال اول، هسته:

```bash
cd apps/api
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m hesabdar
```

سرویس روی `http://127.0.0.1:8000` بالا می‌آید. داده در `apps/api/data` ذخیره می‌شود و وارد مخزن نمی‌شود.

ترمینال دوم، رابط:

```bash
cd apps/web
npm install
npm run dev
```

رابط روی `http://127.0.0.1:5173` است و درخواست‌های `/api` را به هسته می‌فرستد.

داده در همان رایانه می‌ماند. برنامه دیسک را رمزنگاری نمی‌کند؛ این کار با سیستم‌عامل است. اگر سرویس را روی شبکه‌ای غیر از loopback بگذارید، بدون `HESABDAR_ACCESS_TOKEN` بالا نمی‌آید. نمونه تنظیم‌ها در `apps/api/.env.example` است و کلید را در مخزن نگذارید.

## محدودیت‌ها

سقف ردیف و حجم بارگذاری اندازه‌گیری شده‌اند و در [docs/status.md](docs/status.md) از سقف‌های اندازه‌گیری‌نشده جدا شده‌اند. برگه‌ای که از ۵۰۰۰۰ ردیف خواندن بگذرد، در عملیات تغییردهنده فایل ناقص نمی‌سازد.

ارزیابی فرمول زنده با LibreOffice اجرا نشده به علت وابستگی. اتصال مدل زبانی هم اجرا نشده به علت وابستگی. محاسبه پایتون و برنامه‌ریز قاعده‌مند به این دو وابسته نیستند.

نمایش نهایی در اکسل مایکروسافت اینجا اجرا نشده است. خروجی با openpyxl بازخوانی می‌شود. نرم‌افزار خیلی قدیمی ممکن است برگه راست‌به‌چپ را ناقص نشان دهد. جدول محوری بومی اکسل ساخته نمی‌شود. جمله روند، هم محاسبه است و هم نمودار خطی.
