# حسابدار

فضای کار هوشمند برای فایل و داده. در نسخه اول، کاربر فایل جدولی را وارد می‌کند، خواسته‌اش را به زبان طبیعی می‌گوید، و سیستم همان کار را روی داده واقعی انجام می‌دهد و فایل یا گزارش قابل استفاده تحویل می‌دهد.

نام نمایشی محصول **حسابدار** است. نام مخزن `heasabdar` است.

## وضعیت فعلی

بخش صفر (معماری و برنامه ساخت) نوشته شده است. هنوز برنامه قابل اجرایی وجود ندارد. ورود فایل، پردازش اکسل، چت و خروجی در بخش‌های بعد ساخته می‌شوند و تا زمانی که پیاده‌سازی و آزمایش نشده‌اند، قابلیت آماده محسوب نمی‌شوند.

## اصل محصول

کاربر لازم نیست اکسل را حرفه‌ای بلد باشد. سیستم فایل را می‌خواند، عملیات را با کد قابل آزمایش اجرا می‌کند، نتیجه را با داده واقعی می‌سنجد و خروجی را تحویل می‌دهد. توضیح متنی به‌جای اجرای عملیات پذیرفته نیست.

محاسبات قطعی به مدل زبانی سپرده نمی‌شود. مدل زبانی، اگر در دسترس باشد، فقط به فهم زبان و پیشنهاد برنامه ساختاریافته کمک می‌کند.
